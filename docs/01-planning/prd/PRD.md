## 2. 배경·목표

### 배경

NaruWorks는 Git이나 Docker를 모르는 일반 사용자도, 따로 설치하거나 서비스마다 다시 가입하지 않고 오픈소스 서비스를 바로 쓰게 하려는 플랫폼이다. 사용자는 NaruWorks 계정 하나로 공통 화면 안에서 서비스를 이용하고, 결과물은 나루 드라이브에 모여 이후 다른 오픈소스로 바꾸더라도 이어서 작업할 수 있어야 한다.

기존 README와 분석에서는 문서관리·캘린더·카탈로그·요금제·여러 소셜 로그인이 함께 언급되었으나, 1차 출시 범위는 서비스 정의 v1.0과 DEC-001~015를 기준으로 한다. 공유·미리보기·휴지통·회원 탈퇴·카테고리·푸터·저장 위치의 세부 요구는 라운드 04–05에서 확정한 DEC-016~026을 따른다. 본 PRD는 그 범위를 제품 요구로 풀어 쓴다.

### 목표

1차 출시의 목표는 다음과 같다.

- Google 계정 하나로 가입·로그인하면 승인 없이 바로 사용할 수 있게 한다. 이 통합 로그인은 앞으로 붙일 모든 오픈소스의 공통 인증 기반이 된다.
- 나루 화면과 연동 오픈소스 화면에 공통 헤더·푸터를 제공해, 서비스 전환과 회원 메뉴를 같은 방식으로 쓰게 한다. 카테고리는 용도별(문서, 저장소 등)로 나누고, 푸터에는 이용약관·개인정보처리방침, 문의·고객센터, 오픈소스 라이선스 고지, 회사 정보가 들어간다.
- 1차 기본 오픈소스로 Litpage를 연동해, 가입 직후 문서관리를 바로 쓸 수 있게 한다. 문서관리는 직접 개발하지 않는다.
- 연동 오픈소스의 결과물은 나루 드라이브에 자동 저장된다. 사용자는 각 서비스에 처음 들어갈 때 저장 폴더를 고르며, 기본값은 서비스 이름 폴더이다(예: Litpage는 /litpage 아래). 드라이브 화면에서 폴더·파일 관리, 회원 공유(보기/편집 권한 선택)와 비회원 링크 공유(보기만, 1차에 만료·비밀번호 없음), 썸네일 미리보기(불가 시 파일 형식 아이콘), 휴지통(30일 후 자동 삭제)을 다룰 수 있게 한다.
- 관리자는 회원 목록 조회, 회원 정지·해제, 오픈소스 노출·숨김을 할 수 있게 한다.
- 로그아웃하면 연동 오픈소스까지 한 번에 로그아웃되게 한다.
- 회원은 탈퇴할 수 있고, 탈퇴 후 데이터는 30일 보관 후 삭제된다. 보관 기간 안에 재가입하면 데이터를 복구한다.

## 3. 대상 사용자·페르소나

### 일반 사용자 (DEC-005, DEC-007, DEC-020, DEC-021)

Git·Docker·자체 서버 구축을 몰라도, Google 계정으로 가입하면 승인 대기 없이 NaruWorks를 바로 쓰는 사용자. 나루 공통 화면에서 Litpage로 문서를 작성하고, 결과물을 나루 드라이브에서 모아 보거나 내려받고, 회원 또는 링크로 공유할 수 있다. 더 이상 쓰지 않을 때는 탈퇴할 수 있으며, 30일 안에 재가입하면 데이터를 되돌릴 수 있다.

### 운영자(관리자) (DEC-009, DEC-014)

회원과 오픈소스 노출을 운영하는 사용자. 회원 목록을 조회하고, 필요하면 회원을 정지하거나 해제하며, 오픈소스를 노출하거나 숨긴다. 정지된 회원은 다음 로그인부터 차단된다.

1차에서 관리자 승인 가입, 오픈소스 카탈로그·사용 신청 심사는 범위에 두지 않는다 (DEC-005, DEC-006).

## 7. 가정·제약

- 본 문서는 제품 요구만 다루며, 인증 서버·저장소·화면 구현 방식 등 기술 선택은 설계 단계의 일이다.
- **CO-01 도메인**: 기존 환경에 구성된 도메인 정보의 위치만 참조한다. 도메인 값 자체는 본 문서에 적지 않는다.
- **CO-02 Cloudflare**: 기존 Cloudflare 관련 설정의 위치만 참조한다. 설정 값은 본 문서에 적지 않는다.
- **CO-03 소셜 로그인 클라이언트 ID/시크릿**: 기존 환경 설정 위치에 존재한다. 본 문서에는 그 위치만 언급하며, 클라이언트 ID·시크릿 등 비밀 값은 절대 적지 않는다.
- **DB 데이터 이관 없음**: 1차에서 기존 데이터베이스의 회원·파일 등 데이터를 새 환경으로 이관하지 않는다.
- Litpage 문서의 드라이브 저장 파일 형식은 기획에서 정하지 않고 설계 단계로 넘긴다 (DEC-026은 저장 위치만 정함).
