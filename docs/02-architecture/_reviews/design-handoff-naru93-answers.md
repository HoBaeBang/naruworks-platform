## [호배님 결정] 선택지

설계가 대신 정하지 않는다. 답이 오면 해당 문서에 반영한다(이번 작업에서는 수정하지 않음).

- **7 충돌 사본 소유권** — ① 원본 소유자의 파일로 원본 폴더에 귀속 ② 충돌을 만든 편집자의 파일 ③ 소유권은 원본 소유자, 해당 편집자도 접근 가능.
- **37 Q-081** (정식 배포 전) — ① 현행 유지(`Dev. Aslan0`, 사업자 정보 없음) ② 정식 배포 전 법률 확인 후 필요할 때만 표시 ③ 지금 푸터에 사업자·운영자 정보를 넣음.
- **47·62 Q-085** — ① Asia/Seoul 자정, 시작일을 1일째로 셈 ② Asia/Seoul 자정, 시작일 다음날부터 셈 ③ UTC 자정, 시작일을 1일째로 셈.
- **50 Q-087** — ① 열린 세션 차단 상한을 5분 이하로 맞춤(갱신 주기 후보) ② 더 짧게(예: 1분) ③ DEC-098을 바꿔 정지 확정 시 열린 세션도 즉시 종료.

21번의 화면 재개·진행률은 기획 DEC-122 영향 (iii) 확인 질문에 이미 있으므로 여기서 다시 묻지 않는다.
