# 디자인 규칙 요약본 (C1)

디자인 작성·검수 잡은 이 파일만 읽는다. 아래 다섯 스킬 원문과 Web Interface Guidelines 전문은 **매번 로드하지 않는다**.
요약에 없는 판단이 필요할 때만 해당 스킬의 그 절을 1회 Read 한다.

- 출처(2026-11-25 Mac 기준): `frontend-design` 1.1.1, `design-taste-frontend`(tasteskill 2.5), `ui-ux-pro-max` 2.15.0, `hallmark`, `web-design-guidelines`(vercel-labs command.md, 2026-11-19 사본)
- 우선순위: 기획(DEC·FRD·AC) > 디자인 시스템 v0.3(`design-system.md`, `tokens.json`) > 이 요약 > 스킬 원문
- 이 프로젝트는 **제품 앱 화면**이다. 스킬의 마케팅 랜딩 규칙(히어로, 섹션 6~9개, 사진·3D, 히어로 문구 길이 등)은 적용하지 않는다.

## 1. 브랜드·토큰 (확정)

- 브랜드 시안 A "Deep Ink"만. primary `#1E3A5F` / 다크 `#8DB4F5`. accent `#D4A24C` / `#E3B866`은 **장식 전용**(텍스트 금지).
- 글꼴: IBM Plex Sans KR + IBM Plex Sans. 두 가족을 넘기지 않는다. 본문 16px 이상, 줄 간격 1.5 안팎.
- 모든 색·글꼴은 토큰(변수)으로. 화면에 원시 hex를 직접 쓰지 않는다. 표면 순서 `bg` → `surface` → `surface-raised`.
- 반경은 중첩 수준마다 하나, 기본 버튼 스타일은 하나, 본문 폭 하나(데스크톱 1120 가운데).

## 2. 접근성 (DEC-102, WCAG 2.1 AA)

- 텍스트 대비 4.5:1, UI 요소·포커스·필수 경계 3:1. 라이트·다크 모두 확인.
- 모든 조작 요소에 보이는 포커스 표시. 포커스를 가리는 고정 헤더·오버레이 금지.
- 아이콘만 있는 버튼은 이름(라벨)을 문서에 적는다. 장식 아이콘은 이름 없음으로 표시.
- 색만으로 의미를 전달하지 않는다(상태에는 아이콘·문구를 함께).

## 3. 레이아웃·터치

- 데스크톱 1440, 모바일 360(좌우 16). 터치 대상 44×44px 이상, 대상 사이 8px 이상.
- 가로 스크롤 금지. 긴 텍스트는 줄바꿈·말줄임 규칙을 정해 둔다(짧음·보통·아주 긺을 가정).
- 헤더 72 / 푸터 60(일반 회원). 관리자 헤더는 모양 같고 메뉴만 프로필·관리·로그아웃.

## 4. 상태 표시

- 기획에 있는 상태만 그린다. 로딩·오류·빈 상태가 `[미확인]`이면 그리지 않고 열린 질문으로 남긴다.
- 오류 문구는 무엇이 잘못됐고 어떻게 고치는지 말한다. 사과·모호한 문구 금지. 오류는 해당 필드 옆에.
- 빈 화면은 다음 행동을 안내한다. 문구 미정은 `[문구 미확정]`으로 보이게 둔다.
- 파괴적 동작의 확인 대화상자는 **기획에 있을 때만**(DEC-068). 없으면 발명하지 않는다.

## 5. 문구

- 사용자 관점의 쉬운 말, 능동형. 버튼은 결과를 말한다("저장", "숨기기"). 같은 동작은 흐름 내내 같은 이름.
- 영문 Title Case 규칙과 한국어가 충돌하면 한국어 우선. 말줄임은 `…`.
- 숫자는 숫자로("8개"). 날짜·숫자 형식은 로캘 기준이라고 문서에 적는다.

## 6. 금지 패턴 (스킬 공통)

- 가짜 지표·후기·로고 벽·사람 사진, 없는 기능의 발명.
- 보라→파랑 그라디언트, 카드 안의 카드, 이모지 아이콘, 손으로 그린 브라우저·OS 창.
- 모든 제목 위의 대문자 eyebrow 라벨, 자간 넓힌 대문자 라벨, 가운뎃점(·)으로 이은 메타 문자열, 링크 끝의 `→`, 장식용 상태 점.
- 제목 안 한 단어만 기울임·색 강조. 같은 둥근 카드와 같은 회색 그림자를 모든 곳에 반복.
- 01/02/03 번호 표지는 실제 순서가 있을 때만. 장식은 한 곳에만 힘을 준다(골드 수면선·메달리온 점).
- 테마 선택기(Q-090)를 어느 프레임에도 두지 않는다.

## 7. 자기 점검 (그린 뒤 1회)

1. 기획 데이터·동작·상태가 빠짐없이 있는가(발췌 파일 A절 대조).
2. 대비 4.5:1 / 3:1, 터치 44px, 포커스 표시.
3. 6장 금지 패턴이 없는가.
4. 라이트·다크 토큰이 둘 다 바인딩됐는가(원시 hex 없음).
