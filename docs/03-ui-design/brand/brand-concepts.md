# NaruWorks 새 브랜드 시안 3종 (NARU-93 UI 디자인 1단계)

> 기존 Grove Mint 초록/민트 팔레트와 NA 모노그램 로고는 **사용하지 않은 완전 신규 시안**이다. 서비스 톤은 아직 정해지지 않았으므로, 고르기 쉽도록 서로 분명히 다른 세 방향(A 프로페셔널 / B 따뜻함 / C 모던 미니멀)을 대조해 제시한다.

- FigCraft 원본: `brand-concepts.figcraft` (프레임 `BRAND-A`, `BRAND-B`, `BRAND-C`, 동일 구성·1440×1800)
- PNG: `exports/BRAND-A.png`, `exports/BRAND-B.png`, `exports/BRAND-C.png`
- 모티프: "나루(나루터)" = 강을 건너 서비스로 가는 연결. 세 시안 모두 도강/연결을 다른 방식으로 표현했다.
- 대비율은 WCAG 2.x 상대 휘도 공식으로 **수작업 계산**했다(도구 검증 아님). 일반 텍스트 AA 기준 4.5:1.
- 시맨틱 success 초록은 상태색으로만 쓰며 브랜드 주색이 아니다.

## A. Deep Ink · 먹빛 나루

- **키워드**: 신뢰 · 차분 · 정돈
- **근거**: 계정과 파일을 맡기는 서비스이므로 깊은 잉크빛 네이비로 안정감을 주고, 두 기슭을 잇는 아치로 '건너가는 나루'를 표현한다. 금빛 포인트로 차분함 속 완성도를 더한다.

### 로고 컨셉
둥근 사각형 심볼 안의 흰 아치 + 수면선. 두 기슭을 잇는 다리/나루를 단순한 곡선으로 요약. 다크 모드에서는 연한 블루 바탕에 짙은 아치로 반전. 16px에서도 아치 실루엣이 식별된다.

### 장단점
- 장점: 신뢰·보안 인상이 강하고 관리자 화면에 잘 맞음. 대비 여유가 가장 큼. 금색 accent로 차별화.
- 단점: 무겁고 차갑게 느껴질 수 있어 일반 사용자 친근감은 약함. 네이비 계열 서비스가 많아 개성이 약할 수 있음.

## B. Clay Dawn · 새벽 나루

- **키워드**: 친근 · 따뜻함 · 환대
- **근거**: Git·Docker를 모르는 비기술 사용자도 부담 없이 들어오도록, 새벽 나루터의 햇살 같은 클레이·코랄빛으로 환영하는 분위기를 만들고, 작은 나룻배를 심볼로 써서 '건너가는 나루'를 표현한다.

|---|---|---|
| primary | `#B8441F` | `#F0896B` |

| secondary | `#E9A23B` | `#F2B75B` |

| bg | `#FFFAF5` | `#1C1411` |

### 폰트
- SUIT (한글+라틴, 제목·본문) + Nunito(라틴 워드마크·강조)
- 라이선스: SUIT·Nunito 모두 SIL OFL 1.1 — 상업적 웹 사용 무료. (SUIT 라이선스는 배포 전 공식 저장소에서 최종 확인 권장 [미확인: 이 작업에서 웹 확인 안 함])

### 로고 컨셉
원형 심볼 안에 크림색 나룻배(반달 선체 + 돛). 해가 뜨는 나루터의 따뜻한 이미지. 16px에서는 선체/돛의 디테일이 줄어 "원 안의 작은 배"로 보이며, 시안 중 소형 식별성이 가장 낮다.

### AA 대비율 (수작업 계산)
| 항목 | 색 조합 | 대비율 | AA |
|---|---|---|---|
| 라이트 본문 | `#2B1D17` / `#FFFAF5` | 15.68:1 | 충족 |
| 라이트 primary 버튼 | `#FFFFFF` / `#B8441F` | 5.41:1 | 충족 |
| 다크 본문 | `#F7EBE1` / `#1C1411` | 15.48:1 | 충족 |
| 다크 primary 버튼 | `#1C1411` / `#F0896B` | 7.34:1 | 충족 |

### 장단점
- 장점: 비기술 일반 사용자에게 가장 친근. 클라우드/SaaS 사이에서 색이 눈에 띔. 로고 스토리(나룻배)가 직관적.
- 단점: 라이트 primary 버튼 대비가 가장 낮아(5.41) 색을 더 밝히기 어려움. 관리자/보안 신뢰감은 A보다 약함. 오류 red와 primary 계열이 가까워 error 구분에 주의 필요.

## C. Vivid Current · 맑은 물살

- **키워드**: 가벼움 · 선명 · 미니멀
- **근거**: 설치 없이 바로 건너가는 가벼운 속도감을 선명한 인디고-바이올렛과 넓은 여백으로 전달하고, 앞으로 나아가는 쉐브론 두 개로 도강을 표현한다.

| secondary | `#7C3AED` | `#B794F6` |
| accent | `#0EA5E9` | `#38BDF8` |
| bg | `#FFFFFF` | `#0D0E1A` |
| surface | `#F5F5FF` | `#171829` |

### 폰트
- Pretendard (한글+라틴, 제목·본문) + Inter(라틴 워드마크·숫자)
- 라이선스: Pretendard·Inter 모두 SIL OFL 1.1 — 상업적 웹 사용 무료.

### 로고 컨셉
인디고→바이올렛 그라데이션 둥근 사각형 안의 흰 쉐브론 두 개("건너가기/전진"). 형태가 단순해 16px에서도 가장 또렷하다. 다크에서는 연한 라벤더 그라데이션 + 짙은 쉐브론.

### AA 대비율 (수작업 계산)
| 항목 | 색 조합 | 대비율 | AA |
|---|---|---|---|
| 라이트 본문 | `#111827` / `#FFFFFF` | 17.74:1 | 충족 |
| 라이트 primary 버튼 | `#FFFFFF` / `#4F46E5` | 6.29:1 | 충족 |
| 다크 본문 | `#F1F2FA` / `#0D0E1A` | 17.19:1 | 충족 |
| 다크 primary 버튼 | `#0D0E1A` / `#8B93FF` | 7.05:1 | 충족 |

### 장단점
- 장점: 가볍고 현대적이며 파비콘·앱 아이콘 식별성이 가장 좋음. 다크 모드와 잘 맞음. 여러 서비스 아이콘 색을 얹기 쉬운 중립적 바탕.
- 단점: 인디고/바이올렛 SaaS가 흔해 차별성이 약할 수 있음. 따뜻함·환대감은 B보다 약함. 그라데이션 로고는 단색 인쇄/1색 사용 시 변형본이 필요.

## 주의 / 미확인
- FigCraft 헤드리스 렌더러에 지정 폰트(IBM Plex Sans KR, SUIT, Pretendard, Nunito, Inter)가 설치돼 있는지 확인하지 못했다. 시안 이미지는 대체 폰트로 그려졌을 수 있으며, 폰트 이름·라이선스 표기는 의도한 지정값이다 [미확인].
- 대비율은 수작업 계산값이다. 확정 전 대비 검사 도구로 재검증을 권장한다.
