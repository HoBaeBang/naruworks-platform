# Naru Calendar 화면·UX 정책

## 공통 보기

- 연간·월간·주간·일간 보기는 같은 조회 기간과 일정 데이터를 사용한다.
- 기본 진입은 월간 보기다.
- 데스크톱은 이전·다음 버튼으로 기간을 이동한다.
- 모바일 `479px` 이하에서는 월간·주간·일간의 달력 영역을 56px 이상 좌우 스와이프해 이전·다음 기간으로 이동한다. 세로 이동이 더 큰 제스처는 무시한다.

## 캘린더 목록 패널

```text
Naru 내부 캘린더
= 개인·공유 캘린더를 체크박스로 여러 개 동시 표시
= 표시 여부와 새 일정의 기본 저장 대상은 분리

Google 계정
= 기본 접힘 상태의 계정별 상위 그룹
= 실제 표시 선택은 계정 안의 하위 Google Calendar 단위
```

캘린더별 표시 색상은 일정 카드와 목록의 색상 기준이며, 서로 다른 개인·공유·Google 캘린더가 구분되도록 겹침을 줄인다.

## 모바일 월간 보기

폭이 `479px` 이하인 월간 보기에서는 가로 폭을 우선 확보하고 정보 밀도를 조절한다.

| 항목 | 정책 |
| --- | --- |
| 날짜·음력 | 날짜 칸 중앙에 세로로 배치. 음력은 `음`을 생략한 짧은 표기 |
| 일정 정렬 | 종일·기간 일정 우선, 이후 시작 시각 오름차순 |
| 표시 수 | 날짜당 최대 3개, 초과분은 `+N`으로 일간 보기 이동 |
| 제목 | 시간·종일 모두 최대 2줄, 말줄임표 없이 단순 잘림 |
| 줄바꿈 | 공백 우선. `[...]`, `(...)`는 한 묶음으로 유지 |
| 짧은 제목 | 한 줄 높이만 차지 |
| 기간 일정 | 시작·중간·종료 셀을 동일 두께의 연결 막대로 표현 |
| 시간 일정 | 좁은 화면에서는 시간 문자열을 숨기고 제목만 표시 |

달력 내부에는 별도의 스크롤을 만들지 않는다. 페이지 전체의 세로 스크롤로 탐색하며, 일정 제목이 작은 내부 스크롤바에 가려지지 않게 한다.

## 모바일 주간 보기

```text
480px 이상
= 시간축과 7열 시간 그리드

479px 이하 기본
= 날짜별 세로 목록

479px 이하 선택 보기
= 목록 | 시간표 세그먼트로 7열 컴팩트 시간표 전환
= 시간축 28px, 일정 카드에는 제목만 최대 2줄
```

기간을 스와이프해도 사용자가 고른 목록·시간표 방식은 유지한다.

## 일정 생성·수정 모달

- 모바일에서는 모달 헤더와 저장·취소 동작을 접근 가능하게 유지한다.
- 입력 영역만 세로 스크롤하며, 배경 페이지를 스크롤 대상으로 사용하지 않는다.
- 시작·종료 시각은 15분 단위의 완성된 시간 선택 항목으로 제공한다.
- 새 일정은 저장할 내부 캘린더를 명시적으로 선택한다. `VIEWER` 캘린더는 선택지에서 제외한다.
- Google 읽기 전용 일정은 상세만 열고 수정·삭제 동작을 표시하지 않는다.
