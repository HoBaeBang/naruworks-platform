## 1. 범위와 비범위

- **범위** · 나루 웹의 렌더링과 라우팅, 디자인 토큰 적용, 브라우저에서의 API 연동, 시험 도구와 CI, 프런트 배포 형태를 비교한다.

## 4. 비교 기준 [제안]

쿠키·CSRF의 공통 전제는 07·09의 같은 오리진 계약이다. 호스트 전용 `naru_session`은 `Secure`·`HttpOnly`·`SameSite=Lax`로 전달한다. 브라우저는 세션 조회 또는 갱신 응답의 `X-CSRF-Token`을 메모리에 두고 필요한 변경 요청의 헤더에 넣는다. 업로드는 파일당 최대 1 GiB 단일 요청 스트리밍이며, 중단 시 처음부터 재전송한다. 설계에는 8 MiB 분할 업로드와 이어 올리기가 없다. [07 API](../02-architecture/07-api/07-api.md), [09 §2](../02-architecture/09-auth.md#2-나루-세션-쿠키와-csrf)
