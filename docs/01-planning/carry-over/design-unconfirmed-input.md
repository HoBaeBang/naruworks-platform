## 참고(기획 결정 아님)

검수·제작 한계라 기획 확정 대상이 아님.

- 헤드리스 렌더의 대체 글꼴, 화면별 대비 재실측 안 함(DEC-102 토큰 쌍만 사용), 키보드 포커스·읽기 순서·터치·`aria-live` 미검증, 호버·눌림·포커스·비활성 프레임 미작성, 일부 다크·상태 PNG를 눈으로 다시 보지 않음, 수동 줄바꿈이 실제 글꼴·폭에서 달라질 수 있음.
- 초기 바뀜 목록 작성 시점(프레임 목록 근거 부재)의 `[미확인]`, FigCraft MCP 없이는 `.figcraft` 내부 바인딩을 열람하지 못한 검수 기록, 프로토타입 연결 실측 불가.
- AC Must/Should 구분 필드가 없어 AC-FR-*를 Must로 간주한 문서 가정.
- 디자인 시스템·시안 부품 승격 제안(Arch medallion, 선택 동작 띠, Pagination 재사용 등)은 구현/DS 정리 성격. 기획 규칙이 필요한 것만 위에 올렸음.
