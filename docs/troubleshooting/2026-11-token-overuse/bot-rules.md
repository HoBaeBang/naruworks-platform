# 봇 작업 규칙 문구 (C7~C10)

각 봇의 지시문·메모리에 **아래 블록을 그대로** 추가한다. 봇 설정은 저장소 밖이라 자비스가 각 봇에 전달한다.
되돌리기: 추가한 블록을 지운다(추가 전 규칙 문구를 먼저 백업해 둔다).

## C7. 디자인 봇

```
[토큰 절감 규칙 · 2026-11-25 · #96]
- 작성 잡 1개는 화면 1~2개만 다룬다. 4개 묶음으로 내지 않는다.
- 같은 묶음 검수는 최대 2회다. 2회째에도 「막는 문제」가 남으면 더 돌리지 말고 호배님께 결정을 요청한다.
- 경미한 지적은 모아 두었다가 다음 작성 잡에서 한 번에 고친다. 경미 지적만으로 재작성·재검수 잡을 내지 않는다.
- 작성·검수 잡 프롬프트는 docs/design/agent-inputs/prompt-rules.md 를 따른다(요약본·발췌·FigCraft 요약표 사용, 스킬 원문·문서 전체 읽기 금지).
- screens.md 나 screen-data-actions.md 가 바뀌면 docs/design/agent-inputs/excerpts/make_excerpts.py 로 발췌를 다시 만든 뒤 잡을 낸다.
```

## C8. 기획·디자인·설계 봇 공통

```
[보조 작업자 운영 · 2026-11-25 · #96]
- 보조 작업자(executor)는 작업 1~2건마다 새로 시작한다. 한 보조 작업자에게 작업을 계속 이어 붙이지 않는다.
- 인계는 작업 폴더에 둔 1KB 이하 요약 파일로 한다(무엇을 했나 · 결과 경로 · 남은 일).
- 메인 대화에서는 naru-orch status 반복 확인, sleep 대기, PNG 등 이미지 열기를 하지 않는다. 잡 완료 알림을 받은 뒤 결과 파일 경로만 확인한다.
```

## C9. 보고 형식 (자비스 + 각 역할 봇)

```
[보고 형식 · 2026-11-25 · #96]
- 보조 작업자 → 봇: 1KB 이하 요약 + 결과 파일 경로. 원문·로그·긴 표를 붙이지 않는다.
- 봇 → 자비스: 결정이 필요한 것과 결과 경로 위주. 진행 과정 서술은 생략한다.
- 그룹방: 직전 점검과 달라진 점만 올린다. 이미 공유된 내용을 다시 붙이지 않는다.
```

## C10. Claude 작업 동시 실행 (자비스 조율 규칙 · 브리지 코드 C11 대체)

```
[Claude 동시 실행 · 2026-11-25 · #96]
- Claude 쓰기 잡(작성 잡)은 모든 봇을 통틀어 동시에 1개만 돌린다. 순서는 자비스가 정한다.
- 각 봇은 Claude 쓰기 잡을 내기 전에 자비스에게 순서를 받는다. 검수(Gemini·읽기 전용) 잡은 이 제한을 받지 않는다.
- 잡이 끝나면 naru-orch usage <job_id> 로 사용량을 확인하고, 세션당 호출 25회·cache_read 5M을 넘으면 자비스에게 알린다.
```
