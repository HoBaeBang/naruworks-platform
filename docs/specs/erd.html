01 · DATA MODEL

ERD와 데이터 사전

Flyway migration을 기준으로 한 실제 PostgreSQL 명세입니다. PK는 기본 키, FK는 외래 키이며, UNIQUE constraint는 PostgreSQL unique index를 동반합니다.

각 테이블의 설명, 컬럼 논리/물리명, 타입, NULL 허용, 기본값, 제약조건과 명시적 index를 모두 기록합니다. 실제 migration이 최종 기준입니다.

members

회원·추천 관계 기준

  • PK id
  • FK referrer_member_id → members.id
  • UNIQUE referral_code

calendar_events

회원 소유 일정 원본

  • PK id
  • FK member_id → members.id
  • INDEX member_id, start_at

calendar_event_exceptions

반복 회차 예외

  • PK id
  • FK calendar_event_id → events.id
  • UNIQUE event, occurrence

calendar_integrations

외부 OAuth 연결

  • PK id
  • FK member_id → members.id
  • UNIQUE member, provider

member_terms_agreements

약관 동의 이력

  • PK id
  • FK member_id → members.id

calendar_holiday_overrides

공휴일 운영 예외

  • PK id
  • UNIQUE holiday_date
  • CHECK ADD / REMOVE
