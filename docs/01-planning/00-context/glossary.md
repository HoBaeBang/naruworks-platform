# NaruWorks 용어집

상태: 기획 기준선 develop `2f1db92`(PR #99 머지), 라운드 16~19(DEC-081~121) 호배님 승인 완료. 갱신일은 2026-11-26(Asia/Seoul)이다. 문서 간 충돌은 README의 우선순위를 따른다(DEC-081).
관련 문서: `docs/01-planning/00-context/service-definition.md`, `docs/01-planning/02-decision-log/decision-log.md`

관련 문서는 PRD v1.2, FRD·BR v1.5, NFR v1.4, AC·UF v1.3이다.

| 용어 | 정의 | 출처 |
|---|---|---|
| NaruWorks | Git·Docker를 몰라도 Google 계정 하나로 가입해, 나루 공통 화면 안에서 오픈소스 서비스를 바로 쓰고 결과물을 나루 드라이브에 자동으로 모으는 플랫폼. | 서비스 정의 v1.0 |
| 직접 서비스 | NaruWorks가 직접 제공하는 서비스. 1차에는 나루 드라이브가 해당한다. | DEC-006, 서비스 정의 v1.0 |
| 오픈소스 서비스 (연동 오픈소스) | NaruWorks가 직접 만들지 않고, 통합 로그인·공통 화면 틀·나루 드라이브 저장 규칙에 맞춰 연결해 제공하는 외부 오픈소스 서비스. | DEC-001, DEC-002, DEC-004 |
| Litpage | 1차 기본 제공 오픈소스이자 문서관리 서비스. 직접 개발하지 않고 연동한다. | DEC-003 |
| 나루 드라이브 | NaruWorks의 공용 저장소이자 1차 직접 서비스 화면. 연동 오픈소스 결과물의 기본 저장소이며, 폴더·파일 관리, 회원·링크 공유, 썸네일 미리보기, 휴지통, Litpage 문서 열기를 제공한다. 결과물은 서비스별 저장 폴더에 모인다. 1차에는 총용량 제한이 없다. 파일당 1~1,073,741,824바이트를 허용하며, 드라이브와 휴지통 항목은 한 개씩 조작한다. | DEC-004, DEC-006, DEC-010, DEC-011, DEC-016, DEC-018, DEC-019, DEC-026, DEC-086, DEC-107, DEC-116 |
| 통합 로그인 | Google 소셜 로그인 하나로 나루와 연동 오픈소스를 함께 쓰는 인증. 이후 붙이는 모든 오픈소스의 공통 인증 기반이며, 1차 최우선 쟁점이다. | DEC-001, DEC-007 |
| 통합 로그아웃 | NaruWorks에서 로그아웃하면 연동 오픈소스까지 한 번에 로그아웃되는 동작. | DEC-015 |
| 공통 헤더·푸터 | 나루 화면과 연동 오픈소스 화면에 공통으로 붙는 화면 틀. 헤더에는 로고(홈 이동), 서비스 전환 메뉴, 카테고리, 회원 메뉴(프로필·로그아웃)가 들어간다. 푸터에는 이용약관·개인정보처리방침, 문의·고객센터, 오픈소스 라이선스 고지, Dev. Aslan0 표시가 들어간다. | DEC-002, DEC-013, DEC-025, DEC-069, DEC-077 |
| 서비스 목록 홈 | 일반 로그인 후 또는 로그인 상태에서 로그인 화면 주소에 접근했을 때 보이는 화면. 쓸 수 있는 서비스 목록을 보여 준다. | DEC-012, DEC-118, DEC-119 |
| 관리자 | 회원과 오픈소스 노출을 관리하는 운영자. 1차에는 회원 목록 조회(페이지 나눔만), 회원 정지·해제, 오픈소스 노출·숨김, 카테고리·서비스 배정을 관리한다. | DEC-009, DEC-034, DEC-121 |
| 회원 정지 | 관리자가 회원의 이용을 막는 조치. 정지 회원의 재로그인·토큰 갱신·Litpage 진입을 차단한다. 이미 열린 세션은 즉시 종료하지 않는다. 세션은 유휴 7일 또는 최대 30일에 만료된다. 탈퇴 후 재가입해도 정지는 유지되며, 관리자가 회원 목록에서 해제하면 다시 이용할 수 있다. | DEC-009, DEC-014, DEC-092, DEC-098, DEC-093, DEC-114 |
| 노출·숨김 | 관리자가 오픈소스 서비스를 사용자에게 보이게 하거나 숨기는 관리 기능. | DEC-009 |
| 휴지통 | 드라이브에서 삭제한 항목이 바로 사라지지 않고 머무는 공간. 휴지통의 파일은 30일 후 자동 삭제된다. | DEC-011, DEC-019 |
| 서비스 전환 메뉴 | 공통 헤더에서 다른 서비스로 이동할 수 있게 하는 메뉴. | DEC-002, DEC-013 |
| 카테고리 | 공통 헤더에 들어가는 분류 메뉴. 용도별로 나누고 서비스마다 하나를 배정한다. 입력한 이름을 그대로 표시하며, 배정된 서비스가 있으면 삭제를 막고 확인 대화상자를 띄운다. | DEC-002, DEC-013, DEC-024, DEC-034, DEC-115, DEC-120 |
| 회원 메뉴 | 공통 헤더의 회원 관련 메뉴. 프로필과 로그아웃을 포함한다. | DEC-013 |
| 미리보기 | 드라이브에서 파일을 내려받지 않고 내용을 확인하는 기능. 모든 파일 형식을 대상으로 하되, 1차 수준은 썸네일 미리보기이며, 썸네일을 만들 수 없으면 파일 형식 아이콘으로 표시한다. 터치 기기에서는 마우스 올림 썸네일을 생략한다. | DEC-011, DEC-018, DEC-022, DEC-084 |
| 썸네일 미리보기 | 1차 미리보기 수준. 대표 썸네일(이미지 축소본, PDF 첫 페이지, 동영상 첫 장면 등)을 마우스를 올렸을 때 보여 준다. | DEC-018 |
| 파일 형식 아이콘 | 썸네일을 만들 수 없는 파일을, 미리보기 대신 그 형식을 나타내는 아이콘으로 보여 주는 표시. | DEC-022 |
| 공유 | 드라이브에서 다른 사람과 파일을 나누는 기능. 나루 회원 공유와 비회원 링크 공유가 있다. 회원 공유에서는 사용자가 보기/편집 권한을 선택한다. | DEC-011, DEC-016, DEC-017, DEC-023 |
| 링크 공유 | 드라이브 파일을 링크로 비회원에게도 공유하는 방식. 비회원은 보기만 가능하고, 링크 만료와 비밀번호는 1차에 두지 않는다. 비회원이 링크를 열 수 없는 경우에는 공통 안내를 표시한다. | DEC-016, DEC-023, DEC-117 |
| 보기/편집 권한 | 회원 공유에서 사용자가 선택하는 권한. 보기만 할 수 있게 할지, 편집까지 할 수 있게 할지를 정한다. 비회원 링크 공유에는 보기 권한만 적용한다. 다운로드를 금지한 보기 공유와 링크에는 화면용 표시만 제공한다. | DEC-017, DEC-023, DEC-095, DEC-109 |
| 서비스별 저장 폴더 | 사용자가 각 오픈소스 서비스에 처음 들어갈 때 고르는, 그 서비스 결과물을 저장할 나루 드라이브 폴더. 기본값은 서비스 이름 폴더이다(예: Litpage는 /litpage 아래). 오픈소스 교체를 고려한 규칙이다. | DEC-026 |
| 회원 탈퇴 | 회원이 스스로 이용을 종료하는 기능. 1차에 포함한다. 탈퇴 후 데이터는 30일 보관되며, 그 안에 재가입하면 복구된다. | DEC-020, DEC-021 |
| 탈퇴 데이터 보관 | 탈퇴 회원의 데이터를 바로 지우지 않고 30일 보관한 뒤 삭제하는 처리. | DEC-020, DEC-021 |
| 재가입 복구 | 탈퇴 후 30일 보관 기간 안에 다시 가입하면, 같은 Google 계정의 보관 데이터를 복구하는 처리. 정지 여부와 관계없이 데이터를 복구하며, 탈퇴 때 끊긴 받은 공유는 복구하지 않는다. 정지 회원의 정지는 유지된다. | DEC-021, DEC-114 |
| 화면용 표시 | 다운로드 금지 회원 보기 공유와 비회원 링크에서 원본 파일을 보내지 않고 화면으로만 보여 주는 방식. 구체적 형태는 설계 이관이다. | DEC-095, DEC-109 |
| 충돌 사본 | 공유 파일의 동시 편집이 충돌할 때 원본 폴더에 ‘이름 (충돌 사본)’으로 저장하는 사본. 버전은 최근 10개를 30일 보관한다. | DEC-097, DEC-112 |
| 테마 | 프로필에서 선택하고 계정에 저장하는 시스템·밝게·어둡게 설정. 나루 화면과 법적 문서에 적용하며 Litpage 화면은 제외한다. | DEC-101, DEC-113 |
