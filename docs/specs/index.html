NaruWorks · Design Specification

서비스가 커져도 길을 잃지 않는 설계 기준

이 폴더는 기능 구현 전에 확인하는 API 계약, 데이터 모델, 기능 경계를 모은 프로젝트 기준 문서입니다. 실제 코드와 Flyway migration이 바뀌면 같은 작업 단위에서 함께 갱신합니다.

01 · DATA

ERD와 데이터 사전

회원, 일정, 반복 예외, 날짜 메타데이터, 외부 캘린더 연결의 컬럼·기본값·인덱스를 확인합니다.
02 · RELATIONS

관계 ERD (Mermaid)

모든 현재 테이블의 FK 관계, 카디널리티, 삭제 정책과 복합 제약조건을 확인합니다.
03 · API

API 계약

공개 endpoint, 인증 요구사항, 요청·응답의 책임 경계를 확인합니다.
04 · FEATURES

기능 설계

현재 완성된 기능과 다음 기능의 사용자 흐름, 보류한 범위를 구분합니다.
05 · OVERVIEW

서비스 개요

NaruWorks 전체 서비스와 공통 사용자 원칙을 설명합니다.
06 · SEQUENCES

시퀀스 다이어그램

가입, Google 연결, 반복 일정 변경의 흐름을 봅니다.
07 · MEMORY

운영 메모리

프로젝트 정체성, 기술 선택, 장기 결정 사항은 Markdown 운영 메모리에서 관리합니다.
