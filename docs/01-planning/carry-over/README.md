# 이어받는 설정 (CO-01~03)

상태: 위치 기록 (DEC-082, 라운드 16, 2026-11-19). 승인 대기.

이 폴더는 기존 환경에서 이어받는 설정이 **어디에 있는지**만 기록한다. **비밀 값(키, 시크릿, 토큰)과 계정명은 이 문서와 다른 어떤 기획 문서에도 쓰지 않는다.** 값이 필요하면 아래 보관 위치에서 직접 확인한다.

| ID | 항목 | 보관 위치 | 비고 |
|---|---|---|---|
| CO-01 | 도메인 | Cloudflare 대시보드 | 도메인 값은 적지 않는다 |
| CO-02 | Cloudflare 설정 | Cloudflare 대시보드 | 설정 값은 적지 않는다 |
| CO-03 | 소셜 로그인(Google OAuth) 클라이언트 ID·시크릿 | Google Cloud Console | 클라이언트 ID·시크릿은 적지 않는다(NFR-SEC-005) |

## 참조

- PRD §7 가정·제약의 CO-01~03, NFR-SEC-005
- 이번 개정에서 정해진 것은 보관 위치뿐이다. 이어받는 방식(재사용·재발급), 접근 권한자, 값 교체 절차는 [미확인]이며 설계 단계에서 정한다.
