# 열린 질문 (라운드 08 이후)

라운드 08 후보(Q-046~052)는 DEC-040~046으로 해소되었다.

## 설계 이관

- [설계 이관] 인증 구현 방식(Keycloak vs 자체 개발), 수정 Litpage 코드 재사용 여부 (DEC-008)
- [설계 이관] Litpage 문서의 드라이브 저장 파일 형식 (DEC-026은 위치만 정함)

## 보류 세부 (WF 단계에서 질문)
- 프로필 화면 구체 항목
- 이용약관 등 법적 문서의 영어 번역 범위
- 동시 접속 수치 목표 (현재 100명 이내 전제, DEC-036)
