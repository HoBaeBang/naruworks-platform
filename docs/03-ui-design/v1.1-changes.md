## 2. 시안 영향 없음(기록만)

DEC-081, DEC-082, DEC-083, DEC-084, DEC-085, DEC-087, DEC-088, DEC-089, DEC-091, DEC-094, DEC-102, DEC-103, DEC-104, DEC-105, DEC-120

짧은 이유:
- DEC-081~083, 085, 087~089, 091: 기준선·운영·성능·백업 규칙. 화면 요소가 없다.
- DEC-084: 터치 기기 썸네일 생략. WF-05 발췌가 이미 「모바일은 형식 아이콘만」이라 시안은 맞는다(대체 미리보기 수단은 `[미확인]`).
- DEC-094: 로그아웃은 현재 기기만. 헤더 메뉴 문구·동작이 그대로이다(확인 대화상자 없음).
- DEC-102: WCAG 2.1 AA. 요약본 2장에 이미 반영된 기준이다.
- DEC-103: 약관·개인정보 한·영 본문은 할 일(T-01, T-02). 이번에 쓰지 않는다.
- DEC-104: 감사 기록. 기록을 보는 화면이 기획에 없다.
- DEC-105: 저장 용량 운영 경보. 사용자 화면 없음(업로드는 막지 않음).
- DEC-120: 서비스당 카테고리 하나·입력 이름 그대로 표시. WF-14 배정 드롭다운이 이미 단일 선택이다(WF-14 행 13에서 함께 점검).

## 3. 기획 v1.1과 현재 시안 규칙의 충돌 메모

- `design-rules-summary.md` 6장의 「테마 선택기(Q-090)를 어느 프레임에도 두지 않는다」와 WF-15 발췌의 「테마 선택기는 어디에도 없다」는 DEC-113으로 무효가 된다. 요약본 갱신이 필요하다(이 잡은 수정 금지 파일이라 손대지 않음).
- WF-12·WF-10 발췌의 「열린 세션은 로그아웃까지 유지」는 DEC-098로 정정된다(행 19).
- WF-01·WF-08·WF-14·WF-05 발췌의 `[미확인]` 중 DEC-107·108·115~119로 해소되는 항목은 행 3~6, 13~17에 적었다.
- 새로 생긴 `[미확인]`: 로그인 전 임시 언어 저장·로그인 전 테마 적용 방식, 화면용 파일 형태, 충돌 사본 소유권, 폴더 올리기의 모바일 선택 방식, 페이지당 회원 수, 법적 문서 별도 창의 시안 대상 여부(전용 WF 없음), 공유받은 회원이 보는 화면.
