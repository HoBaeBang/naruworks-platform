공개 API 계약

공개 backend 진입점은 api.naruworks.com입니다. API는 Spring Security 세션을 기준으로 현재 회원을 식별하고, 데이터 소유권 판단은 backend에서 수행합니다.

인증 표기: 공개는 세션 없이 접근 가능, 로그인은 승인된 Google 회원 세션 필요, 관리자는 APPROVED + ADMIN 필요를 뜻합니다.

인증과 회원

MethodPath인증설명
GET/api/auth/login공개기존 회원 Google 로그인 시작
GET/api/auth/google?ref={code}공개초대 코드 검증 후 신규 가입 Google 로그인 시작
POST/api/auth/registrations로그인약관 동의 후 내부 Member 최초 생성
POST/api/auth/logout공개HTTP 세션 종료
GET/api/members/me로그인현재 회원 프로필과 권한 조회
GET/api/admin/members관리자회원·추천인 목록 조회

Naru Calendar

MethodPath인증설명
GET/api/calendar/events?from=&to=로그인조회 범위의 내 일정·반복 발생 회차와 선택 Google 일정의 읽기 전용 병합 조회. source, readOnly 포함
POST/api/calendar/events로그인일정 생성
GET/api/calendar/events/{id}로그인소유 일정 상세 조회
PUT/api/calendar/events/{id}로그인단일 일정 또는 반복 원본 전체 수정
DELETE/api/calendar/events/{id}로그인일정 원본과 예외 삭제
PUT/api/calendar/events/{id}/occurrence로그인THIS / THIS_AND_FOLLOWING / ALL 범위 수정
DELETE/api/calendar/events/{id}/occurrence로그인반복 회차 범위 삭제
GET/api/calendar/day-metadata?from=&to=로그인음력·공휴일 읽기 전용 메타데이터

Google Calendar 연결

MethodPath인증현재 계약
GET/api/calendar/integrations/google/authorize로그인세션에 state를 보관하고 Google 동의 화면으로 redirect
GET/api/calendar/integrations/google/callback로그인state 검증, 인가 코드 교환, 암호화 token 저장 후 Calendar로 redirect
GET/api/calendar/integrations/google로그인연결 여부·이메일·상태만 반환. token은 절대 반환하지 않음
