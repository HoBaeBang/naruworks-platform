NaruWorks 서비스 개요

NaruWorks는 홈서버 위에서 Naru 브랜드의 실제 생활형 서비스를 운영하는 플랫폼입니다. 포트폴리오가 아니라 회원이 서비스를 사용하는 입구입니다.

현재

Naru Home

브랜드 첫 화면과 서비스 런처입니다.

현재

Naru Calendar

개인 일정 CRUD, 반복·음력·공휴일, 연/월/주/일 보기, Google Calendar OAuth 연결을 제공합니다.

다음

Google Calendar 가져오기

선택한 캘린더를 읽기 전용으로 가져와 Naru 일정과 함께 표시합니다. Google로 보내기와 양방향 동기화는 보류합니다.

다음

Naru Drive / Docs / Sheets

파일 관리와 문서 도구를 회원·권한 기반 위에서 확장합니다.

분리

StablePay

결제·원장·정산은 별도 모듈로 유지하고 필요 시 API로 연동합니다.

공통 원칙

  • 가입: 유효한 초대 코드 + Google 로그인 + 약관 동의
  • 권한: backend가 회원 상태, 역할, 데이터 소유권을 판단
  • 외부 연동: 최소 권한, refresh token 암호화, 읽기 전용부터 시작
  • 운영: Windows 홈서버 + Docker Compose + Cloudflare Tunnel
