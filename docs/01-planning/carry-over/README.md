# 이어받는 설정 (CO-01~03)

상태: 기획 기준선 develop `2f1db92`(PR #99 머지), 라운드 16~19(DEC-081~121) 호배님 승인 완료. 위치 기록은 DEC-082를 따른다. 라운드 20~22(DEC-122~135) 개정분은 호배님 승인 대기.

기존 환경에서 이어받는 설정의 **보관 위치**와 CO-02 관련 결정 참조를 기록한다. **설정 값, 계정명, 키, 시크릿, 토큰은 기획 문서에 쓰지 않는다.** 값이 필요하면 아래 보관 위치에서 직접 확인한다.

| ID | 항목 | 보관 위치 | 비고 |
|---|---|---|---|
| CO-01 | 도메인 | Cloudflare 대시보드 | 도메인 값은 적지 않는다 |
| CO-02 | Cloudflare 설정 | Cloudflare 대시보드 | 요청 본문 한도는 [미확인]. 이 한도로 1GB 단일 업로드가 막히면 DEC-122에 따라 분할 업로드를 허용한다. |
| CO-03 | 소셜 로그인(Google OAuth) 클라이언트 ID·시크릿 | Google Cloud Console | 클라이언트 ID·시크릿은 적지 않는다(NFR-SEC-005) |

## 참조

- PRD §7 가정·제약의 CO-01~03, NFR-SEC-005
- 이어받는 방식(재사용·재발급), 접근 권한자, 값 교체 절차는 [미확인]이며 설계 단계에서 정한다.

## 개정 이력

- 2026-11-26 (Asia/Seoul) 라운드 20·DEC-122·RB-017/RB-022 반영. CO-02의 한도 확인 위치와 업로드 예외 참조를 기록.
