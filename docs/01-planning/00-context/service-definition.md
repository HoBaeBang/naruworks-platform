# NaruWorks 서비스 정의 v1.0 (2026-11-18)

상태: 승인① 완료 (호배님, 2026-11-18 16:56 KST) / 근거: README(11/11), readme-analysis.md, 인터뷰 라운드 01–03, DEC-001~015

## 1. 한 줄 정의
Git·Docker를 몰라도 Google 계정 하나로 가입해, 나루 공통 화면 안에서 오픈소스 서비스를 바로 쓰고 결과물을 나루 드라이브에 자동으로 모으는 플랫폼.

## 2. 대상 사용자
- 일반 사용자: 누구나 Google 로그인으로 가입하면 승인 없이 바로 사용 (DEC-005, DEC-007)
- 운영자(관리자): 회원과 오픈소스 노출을 관리 (DEC-009)

## 3. 1차 출시 범위 (MVP)
| 영역 | 포함 내용 | 근거 |
|---|---|---|
| 통합 로그인 | Google 소셜 로그인 하나로 나루와 연동 오픈소스를 함께 사용. 모든 향후 연동의 공통 기반(1차 최우선 쟁점). 로그아웃하면 연동 오픈소스까지 한 번에 로그아웃 | DEC-001, 007, 015 |
| 홈 | 로그인 후 쓸 수 있는 서비스 목록 홈 | DEC-012 |
| 공통 화면 틀 | 나루 화면과 연동 오픈소스 화면 모두에 공통 헤더(로고·서비스 전환·카테고리·회원 메뉴)와 푸터 | DEC-002, 013 |
| 문서관리 (Litpage) | 직접 개발하지 않고 오픈소스 Litpage를 연동, 1차 기본 오픈소스 | DEC-003 |
| 나루 드라이브 | 폴더 생성·이름 변경·이동, 업로드·다운로드, 삭제·휴지통, 공유, 미리보기, Litpage 문서 열기. 연동 오픈소스 결과물은 드라이브에 자동 저장. 1차 용량 제한 없음 | DEC-004, 006, 010, 011 |
| 관리자 | 회원 목록 조회, 회원 정지·해제(다음 로그인부터 차단), 오픈소스 노출·숨김 | DEC-009, 014 |

## 4. 1차 제외 (이후 단계)
Naru Calendar, 오픈소스 카탈로그·사용 신청, 드라이브 유료 요금제·5GB 용량 정책, Google 외 소셜 로그인 (DEC-006, 007, 010)

## 5. 이월 항목 (위치만 참조)
