# Naru Calendar 반복 일정과 날짜 메타데이터

## 반복 원본과 조회

반복 일정은 발생 회차마다 DB 행을 만들지 않는다. `calendar_events`의 원본 한 건을 저장하고, 사용자가 조회한 기간 안에서만 발생 시점을 계산한다. 따라서 종료일 없는 반복 일정도 무한히 저장되지 않는다.

| 규칙 | 발생 기준 | 보정 |
| --- | --- | --- |
| `NONE` | 한 번 | 없음 |
| `WEEKLY` | 매주 같은 요일 | 없음 |
| `MONTHLY` | 매월 같은 일자 | 해당 일자가 없으면 그 달 마지막 날 |
| `YEARLY` | 매년 같은 양력 월·일 | 2월 29일은 평년에 2월 28일 |
| `LUNAR_YEARLY` | 매년 같은 음력 월·일 | 아래 음력 보정 적용 |

`recurrenceEndAt`은 선택 사항이다. 값이 없으면 계속 반복하되, 화면이 요청한 조회 구간까지만 계산한다.

### 음력 연간 반복 보정

- 윤달 기준 날짜는 윤달이 없는 해에 같은 평달의 월·일로 반복한다. 예: 윤2월 15일은 평2월 15일로 계산한다.
- 음력 30일이 없는 달은 그 달 마지막 날인 음력 29일로 계산한다.
- 음력 날짜를 다음 달로 넘기지 않는다.

## 반복 회차 수정·삭제 범위

| 범위 | 처리 |
| --- | --- |
| `THIS` | `calendar_event_exceptions`에 해당 회차의 취소 또는 재정의를 저장 |
| `THIS_AND_FOLLOWING` | 기존 원본은 직전 회차에서 끝내고, 선택 회차부터 새 원본 시리즈 생성 |
| `ALL` | 원본 시리즈 전체에 적용 |

`THIS` 회차는 예외 레코드 구조상 다른 캘린더로 이동할 수 없다. 이후·전체 범위는 원본 캘린더와 대상 캘린더에 모두 편집 권한이 있을 때만 이동할 수 있다.

## 기간·종일 일정

- 기간은 별도 테이블 없이 `startAt`, `endAt`으로 표현한다.
- 종일 일정에서 사용자가 고른 종료일은 포함 날짜다. 저장 시 `[시작일 00:00, 종료일 다음 날 00:00)`의 반열린 구간으로 변환한다.
- 예: 9월 14일~17일 종일 일정은 `9/14 00:00`부터 `9/18 00:00`까지 저장한다.
- 시간 일정의 종료 시각은 시작 시각보다 반드시 늦어야 한다.

## 날짜 메타데이터

공휴일과 음력은 회원이 만든 `CalendarEvent`가 아니라 모두에게 공통인 읽기 전용 날짜 메타데이터다.

```text
GET /api/calendar/day-metadata?from=YYYY-MM-DD&to=YYYY-MM-DD
= 음력 월·일·윤달 여부와 공휴일명을 반환
```

표시 우선순위는 `공휴일 > 일요일 > 토요일 > 평일`이다. 공휴일은 요일과 관계없이 빨간색과 공휴일명을 사용한다.

초기 구현은 오프라인 한국 음력 변환 라이브러리와 법정·대체공휴일 계산 규칙을 사용한다. 외부 공공 API가 필요해져도 `CalendarDayMetadataReader` port 구현체만 바꿀 수 있게 유지한다.

## 운영 예외

임시공휴일, 선거일, 계산 오류 정정은 관리자 화면 없이 `calendar_holiday_overrides`로 직접 운영한다.

| operation | 의미 | `holiday_name` |
| --- | --- | --- |
| `ADD` | 기본 계산 결과에 공휴일 추가 | 필수 |
| `REMOVE` | 기본 계산 결과에서 해당 날짜 공휴일 제외 | 사용하지 않음 |
