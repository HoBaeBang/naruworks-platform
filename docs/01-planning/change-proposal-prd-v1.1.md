## 2. 반영할 결정

| DEC | 요지 | 승인 문서 영향 |
|---|---|---|
| DEC-080 | 성공 지표 측정 기간은 출시 후 30일. 동작 지표 5개(회원 정지 차단, 통합 로그아웃, 결과물 자동 저장, 공통 화면 적용, 재가입 데이터 복구)는 100%. 가입 후 즉시 사용 완료율 95% 이상, Litpage 사용 시작율 70% 이상, 드라이브 핵심 과업 완료율 90% 이상, 회원 탈퇴 완료율 100%. 회원 이탈률(기간 중 전체 회원 대비 탈퇴한 회원 비율)을 추가하고 목표는 10% 이하. | PRD v1.0 §1 서론, §6 성공 지표. 승인된 PRD는 승인 전까지 수정하지 않음 |

탈퇴에 대해 처음에는 '10%'라고 답하셨다가, 탈퇴 완료율(요청한 탈퇴를 완료한 비율)과 이탈률(전체 회원 대비 탈퇴 비율)의 의미를 확인한 뒤 둘 다 두기로 정하셨다. 이 경위는 `docs/01-planning/01-interview/round-15.md`에 적는다.

## 4. 의도된 차이 (PRD v1.0 동결, 본문은 고치지 않음)

Gemini 정합성 검토가 짚은 PRD 대비 추적 누락 두 가지는, 승인②로 동결된 PRD v1.0을 후속 결정에 맞게 고치지 않은 **의도된 차이**이다. 이 제안에서도 PRD 해당 문장은 수정하지 않고, 차이만 기록한다.

### 4.1 §4 관리자에 DEC-034(FR-ADM-004)가 없음

PRD v1.0 §4 1차 포함의 관리자 행은 「회원 목록 조회, 회원 정지·해제(다음 로그인부터 차단), 오픈소스 노출·숨김」이고 근거는 DEC-009, DEC-014뿐이다. 이후 DEC-034(카테고리 기본값·관리자 변경, FR-ADM-004)는 FRD·BR에만 반영되었고, 승인된 PRD 범위 표에는 넣지 않았다. FRD는 이를 REQ-007(카테고리)로 추적한다. PRD 본문은 고치지 않는다.

### 4.2 §9에 Q-081이 없음

PRD v1.0 §9는 제품 요구의 [미확인]이 라운드 05에서 해소되었고, 남은 항목은 설계 이관 두 가지라고 적는다. 라운드 14 이후 열린 질문 Q-081(사업자·운영자 정보 표시의 법적 필요, 확인 시점: 정식 배포 전, DEC-079)은 `docs/01-planning/02-decision-log/open-questions.md`와 FR-SHELL-002에만 두고, 승인된 PRD §9에는 추가하지 않는다. PRD 본문은 고치지 않는다.

## 5. 바꾸지 않는 것

- 승인된 PRD v1.0 본문(이 제안이 승인되기 전까지).
- 결정 로그의 기존 DEC 행과 승인 기록 행.
- FRD·BR·NFR 본문, AC·UF 본문, matrix.csv. 성공 지표는 PRD §6 항목이며, AC와 matrix에는 해당 참조가 없다.
- Q-081. 열린 질문으로 유지한다.
